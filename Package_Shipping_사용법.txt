====================================================
 Retrieve - Windows Shipping 패키징 스크립트 사용법
====================================================

[ 파일 위치 ]
Package_Shipping.bat 은 Retrieve.uproject 와 같은 폴더(프로젝트 루트)에
있어야 합니다. 위치를 옮기면 동작하지 않습니다.

[ 사용 방법 ]
1. Package_Shipping.bat 을 더블클릭합니다.
2. 검은 콘솔 창이 뜨고 자동으로 엔진을 탐지한 뒤 패키징을 시작합니다.
3. 프로젝트 규모에 따라 보통 3~10분 정도 걸립니다. 창을 닫지 말고 기다려주세요.
4. 끝나면 "PACKAGING SUCCEEDED!" 또는 "PACKAGING FAILED" 메시지가 뜨고,
   아무 키나 누르면 창이 닫힙니다.

[ 결과물 위치 ]
패키징이 성공하면 실행 파일은 아래 경로에 생성됩니다.
  (프로젝트 폴더)\..\Package\Windows\Retrieve.exe

예) 프로젝트가 다음 경로에 있다면
  C:\Users\본인이름\...\7th-Team2-Final-Project
결과물은 다음 경로에 생성됩니다.
  C:\Users\본인이름\...\Package\Windows\Retrieve.exe

[ 사전 준비물 (패키징하려는 PC에 반드시 설치돼 있어야 함) ]
1. Unreal Engine 5.7
   - 기본 설치 경로(C:\Program Files\Epic Games\UE_5.7 등)에 설치했다면
     스크립트가 자동으로 찾습니다.
   - 다른 위치에 설치했다면, Package_Shipping.bat 을 메모장으로 열어서
     "ENGINE_ROOT" 로 시작하는 줄을 찾아 실제 설치 경로로 수정한 뒤 저장하세요.
2. Visual Studio (Build Tools 포함, C++ 데스크톱 개발 워크로드)
   - C++ 소스 코드를 컴파일하기 위해 필요합니다. 없으면 빌드 단계에서 실패합니다.

[ 실패했을 때 ]
- 콘솔 창에 나온 로그를 위로 스크롤해서 어떤 단계(Build/Cook/Stage/Package)에서
  실패했는지 확인하세요.
- "ENGINE_ROOT" 를 못 찾는다는 오류가 뜨면, 위 사전 준비물 1번 항목대로
  엔진 경로를 직접 지정해주세요.
- 그래도 안 되면 로그 내용을 그대로 복사해서 공유해주세요.

[ 참고 ]
이 스크립트는 아래 옵션으로 RunUAT BuildCookRun을 실행합니다.
  -platform=Win64 -clientconfig=Shipping
  -cook -build -stage -pak -iostore -package -archive
  -nocompileeditor -skipbuildeditor -CrashReporter

-skipbuildeditor 옵션 때문에, Blueprint 구조에 영향을 주는 C++ 헤더(UPROPERTY/
USTRUCT 등)를 수정한 직후에는 에디터를 한 번 직접 실행해서(또는 에디터 모듈을
재빌드해서) 최신 상태로 컴파일해 둔 뒤 패키징해야 정확한 결과물이 나옵니다.
단순 로직 수정(.cpp 내부 함수 구현 변경 등)만 있었다면 상관없습니다.
