# [TIL] POI를 강조하는 기법들 (레벨 디자인)

> **Today I Learned** | Level Design | POI | Composition | Lighting | Visual Language

---

## 0. 핵심 원리: 강조 = 대비(Contrast)

> **POI는 "주변과 다르기" 때문에 눈에 띈다.** 강조의 본질은 절대적 화려함이 아니라 **주변과의 차이**다.

밝기·색·크기·형태·움직임 중 **무엇이든 주변과 어긋나면** 시선이 꽂힌다. 그래서 POI 강조의 절반은 "POI를 키우는 것"이 아니라 **"주변을 죽이는 것"**(고립·여백)이다.

게슈탈트 4대 강조 원리:

| 원리 | 설명 | 레벨 적용 |
|---|---|---|
| **Contrast** | 주변과 다름 | 밝기·색·스케일 차이 |
| **Isolation** | 홀로 떨어짐 | 주변 비우기(여백) |
| **Convergence** | 선이 모임 | 길·능선이 POI로 수렴 |
| **Anomaly** | 패턴 깨기 | 반복 속 하나만 다름 |

## 1. 형태·구도로 강조

| 기법 | 방법 | 효과 |
|---|---|---|
| **실루엣(스카이라인)** | 하늘·밝은 배경 앞에 POI 윤곽을 띄움 | 거리·역광에도 형태 인지 |
| **수직성(Verticality)** | 주변보다 압도적으로 높게 | 어디서든 보이는 랜드마크 |
| **스케일 대비** | 주변 요소 대비 거대/특이 | 무의식적 주목 |
| **프레이밍** | 아치·나무·협곡으로 액자처럼 감쌈 | 시선을 POI로 가둠 |
| **고립/여백** | POI 주변을 의도적으로 비움 | 잡음 제거 → 단독 부각 |

```
❌ POI를 디테일 빽빽한 구역 한가운데 → 묻힘
✅ POI 주변에 여백(빈 광장·평지) → 시선이 자연히 모임
```

> **실루엣 테스트**: POI를 검은 단색으로 칠해도 "무엇인지" 알아보면 형태 강조 성공. 안 되면 윤곽을 더 특이하게.

## 2. 빛으로 강조 (가장 강력)

| 기법 | 방법 |
|---|---|
| **명암 대비** | POI만 밝게, 진입로·주변은 어둡게 |
| **빛기둥(God Ray)** | Light Shaft / 볼류메트릭 포그 + 강한 빛 → 하늘에서 내리꽂는 광선 |
| **발광(Emissive)** | POI 자체가 빛남 (룬·크리스탈·창문) + Bloom |
| **역광/림라이트** | 뒤에서 빛 → 가장자리 발광, 신비감 |
| **시간대 연출** | 일몰 황금빛이 POI에만 닿게 라이트 배치 |

```
❌ 맵 전체 균일 조명 → POI가 배경에 녹음
✅ POI에 스포트/볼류메트릭 + 주변 노출 낮춤 → 자연스러운 시선 유도
```

> 어두운 던전의 **한 줄기 빛 아래 제단** = 빛 대비만으로 완성되는 POI. 빛은 설명 없이 "여기가 중요하다"를 외친다.

---

## 3. 색으로 강조

| 기법 | 방법 |
|---|---|
| **보색 대비** | 주변이 차가운 톤이면 POI는 따뜻한 톤(또는 반대) |
| **채도 대비** | 주변 채도를 낮추고 POI만 선명하게 |
| **컬러 스크립트** | "이 색 = 목표/중요" 규칙을 게임 전체에서 일관 유지 |
| **발광색** | 포탈=보라, 세이브=금색 등 의미 코드화 |

```
회색빛 폐허(저채도) 속 → 푸른 마법 포탈(고채도 보색) = 즉시 시선 집중
```

> 색 강조는 **주변 채도를 깎을수록** 강해진다. POI 채도만 올리는 것보다 효과적일 때가 많다.

---

## 4. 동적 요소로 강조 (움직임 = 시선 자석)

정지된 화면에서 **움직이는 것**은 본능적으로 시선을 끈다.

| 요소 | 예시 |
|---|---|
| **VFX** | 떠오르는 입자, 소용돌이, 에너지 흐름 |
| **물리 움직임** | 펄럭이는 깃발, 흔들리는 등불, 회전 구조물 |
| **빛 변화** | 맥동(pulse)하는 발광, 깜빡이는 신호 |
| **연기/증기** | 굴뚝 연기, 모닥불 → 멀리서 "사람/거점" 암시 |
| **사운드** | 거리별 오디오 큐(종소리·웅웅거림)로 청각 유도 |

> 멀리서 **연기 한 줄기**는 그 자체로 강력한 POI다. "저기 뭔가 있다"를 조용히 말한다.

---

## 5. 유도선으로 끌어들이기 (Leading Lines)

POI 자체를 꾸미는 것 외에, **주변 지형이 POI를 가리키게** 한다.

```
길·강·능선·협곡·건축 라인·울타리 → 소실점이 POI를 향하게 배치
```

- 도로가 자연스럽게 POI 입구로 휘어지게
- 산맥/계곡의 V자가 POI를 프레이밍
- 빛줄기·그림자 방향도 유도선이 된다

> 플레이어는 **선을 따라 시선과 발을 옮긴다.** POI로 수렴하는 선을 깔면 "가야 할 곳"이 무의식에 박힌다.

## 6. 기술적 구현 (UE5)

| 목적 | 구현 |
|---|---|
| **외곽선 하이라이트** | `Render CustomDepth Pass` + Post Process Material로 아웃라인(상호작용 POI 강조) |
| **발광 + 블룸** | Emissive 머티리얼 + Post Process Bloom Threshold 조정 |
| **빛기둥** | Directional/Spot Light `Light Shaft Bloom` + Exponential Height Fog `Volumetric Fog` |
| **원거리 가시성** | POI 전용 HLOD Layer + 큰 Loading Range → [HLOD+POI TIL](UE5_HLOD_PackedLevelActor_POI.md) |
| **포스트프로세스 국소 강조** | POI 구역 Bounded PPV로 노출·채도 차등 |
| **대기 원근(Aerial Perspective)** | Sky Atmosphere로 먼 POI에 푸른 안개 → 깊이감, "멀리 거대한 것" 인지 |

```
상호작용 가능 POI → CustomDepth 스텐실 값 부여 → PP 머티리얼이 그 픽셀만 외곽선
```

> 거리별로 강조 수단을 바꾼다: **원거리=실루엣·HLOD·빛기둥**, **중거리=색·스케일**, **근거리=VFX·아웃라인·사운드**.

## 7. 강조의 함정 ⚠️ (과유불급)

| 함정 | 결과 | 대응 |
|---|---|---|
| 모든 걸 다 강조 | 아무것도 안 튐 | **POI 위계** 설정(주 1, 부 다수) |
| POI마다 다른 강조 규칙 | 플레이어 학습 불가 | 강조 언어 **일관성** |
| 강조 수단 과적(빛+색+VFX+크기 전부) | 촌스럽고 산만 | **1~2개 수단**으로 절제 |
| 주변을 안 죽임 | 대비 약함 | 고립·여백·채도 down 병행 |
| 강조했는데 못 감 | 어포던스 부재 | 갈 수 있다는 신호(길·입구) 동반 |

> 핵심은 **위계(hierarchy)**. 전부 외치면 소음이다. 주 POI 하나를 가장 강하게, 부 POI는 약하게 차등.

## 핵심 요약

> - **강조 = 대비.** POI를 키우기 전에 **주변을 죽여라**(고립·여백·채도 down). 절반은 거기서 끝난다.
> - **빛이 가장 강력하다.** 명암 대비·빛기둥·발광 하나로 "여기가 중요"가 전달된다.
> - **거리별로 수단을 바꾼다**: 원거리=실루엣·수직성·HLOD, 중거리=색·스케일, 근거리=VFX·외곽선·사운드.
> - **유도선으로 끌어와라.** 길·능선·빛이 POI로 수렴하면 발과 시선이 따라온다.
> - **위계와 절제.** 다 강조하면 아무것도 안 튄다. 주 POI 하나만 가장 세게, 수단은 1~2개로.
